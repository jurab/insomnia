## 2026-02-17 (Update - Provider Browser Workflow)

### Goal
Turn the debug sidebar into a dedicated provider API browser workflow and remove backend mode.

### Changes Made

1. **Sidebar provider-first controls**
   - Replaced top-left controls (`Base Environment`, cookies, certs, modal trigger) with provider entries:
     - `Kosik`
     - `Rohlik`
     - `Knuspr`
   - Clicking a provider now runs background workflow:
     - reuse persisted provider cookies if available
     - open popup only when needed
     - sync cookies to workspace jar
     - generate provider requests
   - File:
     - `packages/insomnia/src/routes/organization.$organizationId.project.$projectId.workspace.$workspaceId.debug.tsx`

2. **Direct-only provider mode**
   - Removed `backend` mode from provider explorer domain model and generation path.
   - Provider config now stores a single endpoint list (direct-oriented).
   - Request generation now targets provider folder directly and uses only:
     - `{{ _.provider_direct_base_url }}`
   - Legacy provider mode folders (`backend`, `direct`) are cleaned from provider tree during generation.
   - Files:
     - `packages/insomnia/src/provider-explorer/types.ts`
     - `packages/insomnia/src/provider-explorer/provider-config.ts`
     - `packages/insomnia/src/provider-explorer/generate-requests.ts`
     - `packages/insomnia/src/ui/components/provider-explorer/provider-explorer-modal.tsx`

3. **Create menu browser action**
   - Added `Browser` action in the `+` dropdown next to endpoint filter.
   - Opens provider popup for currently selected provider.
   - Persists cookies on successful login.
   - File:
     - `packages/insomnia/src/routes/organization.$organizationId.project.$projectId.workspace.$workspaceId.debug.tsx`

4. **Discovered endpoint capture from popup browsing**
   - Popup auth flow now captures browsed request structure and returns discovered requests.
   - Discovered requests are upserted to:
     - `Provider Explorer/{Provider}/Discovered`
   - Capture is normalized to endpoint structure (`:id` templating for ids/tokens).
   - Added capture diagnostics to main logs:
     - `[provider-auth] capture stats` with seen/filtered/kept counts + sample paths.
   - Files:
     - `packages/insomnia/src/main/provider-auth-in-window.ts`
     - `packages/insomnia/src/provider-explorer/types.ts`
     - `packages/insomnia/src/provider-explorer/generate-requests.ts`
     - `packages/insomnia/src/routes/organization.$organizationId.project.$projectId.workspace.$workspaceId.debug.tsx`

### Technical Findings

- Main-process changes (Electron popup capture/auth code) may require full `npm run dev` restart; Vite HMR alone is not always sufficient.
- After restart, capture/discovery behaved correctly and produced a large set of endpoints.

### Validation

- ESLint fixes applied for touched files.
- Type-check passed repeatedly:
  - `npm run type-check -w insomnia`


## 2026-02-17 (Update - UI Declutter & Unified Top Bar)

Streamline the debug view: remove tabs, remove tutorial panel, remove sidebar chrome, add unified top bar with provider dropdown + URL.

### Changes Made

1. **Removed tab bar from debug view**

   - Files:
     - `packages/insomnia/src/routes/organization.$organizationId.project.$projectId.workspace.$workspaceId.debug.tsx`

2. **Removed ScratchPadTutorialPanel (Documents/Collections/MCP Clients/Mocks/Environments)**

   - Files:
     - `packages/insomnia/src/routes/organization.$organizationId.project.$projectId.workspace.$workspaceId.debug.tsx`

3. **Hardcoded provider base URLs**
   - Added `baseUrl` field to `ProviderConfig` type.
   - Hardcoded: Kosik=`https://www.kosik.cz`, Rohlik=`https://www.rohlik.cz`, Knuspr=`https://www.knuspr.de`.
   - Request generation now uses provider `baseUrl` instead of `{{ _.provider_direct_base_url }}` template variable.
   - Files:

     - `packages/insomnia/src/provider-explorer/provider-config.ts`
     - `packages/insomnia/src/provider-explorer/generate-requests.ts`

4. **Unified top bar (provider dropdown + URL + send)**
   - Removed sidebar top bar (back button, Scratch Pad dropdown, Run button).
   - Removed provider buttons section from sidebar.
   - Removed URL display from request pane header.
   - Moved `RequestUrlBar` (send button) from request pane bottom to top bar.
   - Added full-width top bar above the sidebar/main split with:
     - Provider dropdown (Backend/Kosik/Rohlik/Knuspr) — selecting triggers auth workflow
     - URL display (truncated, full width)
     - Send button (right side)
   - Files:
     - `packages/insomnia/src/routes/organization.$organizationId.project.$projectId.workspace.$workspaceId.debug.tsx`
     - `packages/insomnia/src/ui/components/panes/request-pane.tsx`
     - `packages/insomnia/src/ui/css/main.css`

### Technical Findings

- `.pane` CSS uses `grid-template-rows: var(--line-height-sm) minmax(0, 1fr)` — removing PaneHeader requires overriding to single-row grid, otherwise content collapses into the header-height row.
- `PanelGroup` from react-resizable-panels can't have non-Panel direct children; wrapping in a plain div with flex-col layout works.
- Dev app requires `npm run dev` (not `npm run start`).

### Validation

- Type-check passed: `npm run type-check -w insomnia`
- App restarts cleanly with new layout.
