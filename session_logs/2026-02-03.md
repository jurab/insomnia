### Technical Findings

- Insomnia uses NeDB (newline-delimited JSON) for local storage at `~/Library/Application Support/Insomnia/`
- **Dev app uses separate data dir**: `~/Library/Application Support/insomnia-app/`
- Key files: `insomnia.Request.db`, `insomnia.Workspace.db`, `insomnia.Environment.db`
- App requires full restart to pick up external DB file changes (no file watching)
- Already has MCP client support (can connect TO MCP servers)
- Plugin system is hook-based, can't run background processes
- **Singleton lock files** can cause "Failed to get instance lock" errors - clear with:
  ```bash
  rm -f ~/Library/Application\ Support/insomnia-app/SingletonLock ~/Library/Application\ Support/insomnia-app/SingletonSocket ~/Library/Application\ Support/insomnia-app/SingletonCookie
  ```
